## 3. 变量隔离说明

- S1 商品浏览使用本批次 productId，避免依赖既有业务商品。
- S2 公开浏览固定从同一客户端 IP 发起；会员写请求使用上述 MEMBER 账号。
- S3 以 N=10、M=20 验证竞争，且每个下单请求使用唯一的 `perf13-20260830-001-` 幂等键。
- 12 个 MEMBER 账号用于避免单一会员令牌桶掩盖库存竞争；它们不是为了绕过 Gateway，而是隔离限流与库存两个变量。
- Redis 热点库存只作为快速过滤；MySQL 条件更新仍是最终不超卖边界。
